# Profile assets

These are the existing project icons, with their original pixels (cropped, not redrawn). No screenshot or terminal output is simulated.

- `storedeck-icon.png`: Storedeck's public website icon, from `apps/landing/public/app-icon.png`.
- `gplay-icon.png`: gplay's public website icon, from `website/public/icon-192.png` in `PollyGlot/google-play-cli`.
- `verbum-icon.png`: Verbum's macOS application icon, from `macos/Runner/Assets.xcassets/AppIcon.appiconset/app_icon_128.png`.

The gplay icon has its transparent rounded corners filled with its own edge color. The Storedeck and Verbum icons are cropped to their artwork (no transparent margin), because GitHub paints a grey tile behind every README image and the margin made it visible. The README declares them at 56 px. Source provenance is also embedded in the PNG metadata.
